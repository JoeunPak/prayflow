# AD SOLUTION 럭키 가챠 (다산 현대 아울렛 팝업용)

`index.html` 파일 하나로 돌아가요. **설치도 인터넷도 필요 없어요.**
USB에 담아 노트북에 복사한 뒤 크롬으로 더블클릭해서 열면 끝이에요.

## 경품 기본 설정

| 등수 | 경품 | 확률 | 준비 수량 |
|---|---|---|---|
| 1등 | 베리어 리페어 밤 (본품) | 4% | 50개 ※ |
| 2등 | 루트캄 앰플 | 6% | 80개 |
| 3등 | 마스크팩 1매 | 10% | 100개 |
| 4등 | 샘플 세트 (세럼 + 밤) | 30% | 200개 |
| 5등 | 사탕 | 50% | 1,000개 |

※ 밤 수량은 회의록 메모(50개) 기준이에요. 관리자 창(`A`)에서 바로 고칠 수 있어요.

- 경품이 다 떨어지면 그 경품은 화면에 "소진"으로 표시되고, 그 확률은 남은 경품들에 비율대로 나눠져요.
- 결과는 버튼을 누르는 순간 정해지고 바로 저장돼요. 연출 중에 프로그램이 꺼져도 기록은 남아요.
- 수량과 기록은 이 노트북의 크롬에 저장돼요. 다른 브라우저나 시크릿 창으로 열면 처음부터 시작하니 **항상 같은 크롬 일반 창**으로 여세요.

## 화면 흐름

1. 대기 화면: 가챠 머신 + 경품표 + "버튼을 눌러 가챠를 돌려주세요!"
2. 버튼을 누르면 손잡이가 돌아가고 캡슐들이 섞여요 (약 1.7초)
3. 캡슐이 떨어지고, 흔들릴 때마다 색이 바뀌다가 마지막에 등수 색으로 멈춰요. 1·2등은 더 오래 흔들려서 긴장감이 커져요.
4. 캡슐이 열리면서 빛 + 꽃가루 + 효과음과 함께 당첨 카드가 나와요. 1등은 **JACKPOT!**
5. 버튼을 한 번 더 누르거나 25초가 지나면 대기 화면으로 돌아가요.

## 키 조작

| 키 | 기능 |
|---|---|
| `Space` `Enter` `PageDown` `PageUp` `→` `←` `↑` `↓` `B` `.` / 화면 클릭 | 가챠 돌리기, 결과 닫기 |
| `F` | 전체 화면 |
| `M` | 소리 켜기/끄기 |
| `A` (오른쪽 아래 ⚙) | 관리자 창: 확률·수량 수정, 기록 보기, 마지막 추첨 취소, CSV 저장, 초기화 |
| `1`~`9` / `0` | 참여권 모드에서 참여권 추가 / 0회로 초기화 |
| `Esc` | 결과 화면이나 관리자 창 닫기 |

한/영 상태와 상관없이 동작해요.

## 외부 버튼 연결: 누르면 TV에 결과가 나오게 하기

원리는 간단해요. **외부 버튼은 "키보드 한 키"처럼 동작하고, 노트북 화면은 HDMI로 TV에 띄워요.**

```
[손님이 누르는 버튼] --블루투스/USB--> [노트북 (크롬 전체 화면)] --HDMI--> [TV]
```

### 1) 버튼 고르기 (아래 중 하나)

| 방법 | 장점 | 주의 |
|---|---|---|
| **무선 프레젠터 (PPT 리모컨)** — 추천 | 2~3만 원, USB 수신기만 꽂으면 바로 됨, 10m 이상 거리 | 버튼이 작아요. 아무 버튼이나 눌러도 되게 해놨어요 (PageDown/PageUp/B/.) |
| **USB 빅 버튼 / 풋스위치** ("USB 원버튼 키보드"로 검색) | 손님이 누르기 재밌는 큰 버튼, 연출 효과가 좋아요 | 유선이면 케이블 길이를 확인하세요. 키를 `Enter`나 `Space`로 설정 |
| 무선 숫자 키패드 | 싸고 구하기 쉬움 | `Enter` 키만 쓰도록 안내 |
| 블루투스 셀카 리모컨 | 아주 쌈 | 볼륨키를 보내는 제품이 많아서 윈도우에서는 잘 안 될 수 있어요. 사기 전에 테스트하세요 |

팝업에서는 **USB 빅 버튼(카운터 위, 손님용) + 무선 프레젠터(직원 주머니, 예비용)**를 같이 쓰는 걸 추천해요. 둘 다 꽂아두면 어느 쪽으로 눌러도 돼요.

### 2) TV 연결

1. 노트북과 TV를 **HDMI 케이블**로 연결해요. 부스가 좁으면 노트북은 매대 아래에 두고 케이블을 길게 (3~5m) 준비하세요.
2. 윈도우: `Win + P` → **복제**를 고르면 노트북과 TV에 같은 화면이 나와요. 가장 간단해요.
   - 노트북 화면을 따로 쓰고 싶으면 **확장**을 고르고, 크롬 창을 TV 쪽으로 끌어다 놓아요.
3. 크롬에서 `index.html`을 열고 `F`를 눌러 전체 화면으로 바꿔요.
4. TV 화면 비율 설정은 "원본/화면 맞춤(Just Scan)"으로 해야 가장자리가 잘리지 않아요.

### 3) 꼭 확인할 것 (버튼이 안 먹는 이유는 대부분 이것)

- **크롬 창이 선택된 상태**여야 버튼이 먹어요. 다른 창이나 알림을 클릭했다면 TV 화면을 한 번 클릭해 주세요.
- 윈도우 **절전·화면 꺼짐을 "안 함"**으로 바꾸고, 노트북 덮개를 닫아도 꺼지지 않게 설정해요 (전원 옵션 → 덮개를 닫으면 → 아무것도 안 함).
- 윈도우 알림, 자동 업데이트, 카카오톡 같은 팝업은 꺼두세요.
- 소리를 내려면 TV(HDMI)로 소리가 나오는지 확인하고, 시끄러운 매장이면 `M`으로 꺼도 돼요.
- 전원 어댑터는 항상 꽂아두세요.

### 더 안정적으로: 크롬 키오스크 모드 (선택)

바탕화면에 크롬 바로가기를 하나 더 만들고, 대상 끝에 아래를 붙이면 창 없이 가챠 화면만 꽉 차게 열려요.

```
--kiosk "file:///C:/gacha/index.html"
```

(`C:/gacha/` 부분은 실제 파일 위치로 바꾸세요. 종료는 `Alt + F4`)

## 현장 운영 순서

1. **전날 리허설**: 관리자 창(`A`)에서 **테스트 모드**를 켜고 버튼·TV·소리를 확인해요. 테스트 결과는 수량과 기록에 반영되지 않아요.
2. **오픈 전**: 테스트 모드를 끄고, 남은 수량이 실제 준비 수량과 맞는지 확인해요.
3. **운영 중**: 결제 금액(3만 원 이상)은 직원이 확인한 뒤 손님에게 버튼을 누르게 해요.
   - 아이들이 버튼을 계속 누를까 걱정되면 **참여권 모드**를 켜세요. 직원이 노트북 숫자키 `1`을 눌러야 1회 뽑을 수 있어요 (10만 원 이상 2회면 `2`).
   - 잘못 뽑았으면 관리자 창의 **마지막 추첨 취소**로 수량을 되돌려요.
4. **마감**: 관리자 창에서 **기록 CSV 저장**을 누르면 엑셀로 열리는 파일(추첨 시간, 등수, 경품별 지급·남은 수량)이 저장돼요. 일일 매출 보고 때 같이 공유하세요.
5. 다음 날은 그대로 이어서 쓰면 돼요. 기록과 수량이 유지돼요. **전체 초기화는 행사가 끝난 뒤에만** 하세요.
